# AgileCampus V1 功能取舍

日期：2026-09-21

V1 只服务一条可演示的闭环：

```text
今日待处理 → 项目任务 → 人 / Agent 接力 → 人工确认 → 成果沉淀
```

## 保留在主路径

| 入口 | 作用 | 判断 |
|---|---|---|
| 今日 | 汇总所有需要本人动作的事项 | 唯一的跨项目行动入口 |
| 项目 / 任务 | 拆分、交接、推进和验收任务 | 从项目列表进入后的第一画布 |
| 项目 / 概览 | 看项目进展、风险和当前接力 | 需要看全局状态时再进入 |
| 项目 / Agent | 查看 Agent、上下文、运行记录和待确认动作 | AI 深度融合主画布 |
| 项目 / 成果 | 决策、证据、成果和过程沉淀 | 项目收尾与复盘入口 |
| 协作中心 | 查看求助和 AI 成员状态 | 不重复承接待办 |
| 资料库 | 跨项目检索成果和文档 | 交付物复用入口 |

主导航只显示「今日 / 项目 / 协作中心」三项；资料库和设置仍可从账户菜单进入，深链不变。

## 从主路径移出或合并

| 功能 | 处理方式 | 原因 |
|---|---|---|
| 今日页「项目脉搏」 | 移除，保留「项目」一级入口 | 与项目列表重复，不能直接完成动作 |
| 协作中心「AI 动作审批」与「AI 待确认」 | 移除重复列表，统一进入「今日」处理 | 同一件事不在两个页面出现 |
| 时间线、活动流、复盘 | 保留为成果页的次级链接 | 有价值，但不是每天的主动作 |
| 健康度总览 | 保留深链，不放一级导航 | 风险已在概览与今日行动队列出现 |
| 团队、标签、资源、令牌管理 | 保留管理页，不放主路径 | 配置频率低，避免干扰项目执行 |
| 全局悬浮求助 | 暂不删除，作为低门槛安全阀 | 求助是跨页面动作，不能因为精简而失去 |

## 设计约束

1. 跨项目要做什么，只去「今日」。
2. 项目列表进入后直接落在「任务」，先做事，再看概览。
3. AI 在做什么，只去「Agent」。
4. 做完留下什么，只去「成果」。
5. 每个动作只保留一个主入口；其他地方只提供明确的深链，不复制列表。
