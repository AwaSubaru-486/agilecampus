# 原页面新手引导验收（2026-10-07）

用户明确纠正：教程应带领用户操作已有页面，不作为独立练习页面。本轮替代此前 `tutorial-example/review.md` 描述的版本；旧截图和说明仅作历史记录。

## 交互路线

18 步主线使用现有团队创建、成员、项目创建、规划与迭代、任务执行、AI 协作、团队资源和项目复盘页面。`/tutorials` 仅提供课程目录及恢复入口；旧 `/tutorials/example` 地址重定向回目录，独立工作区已移除。

用户在原表单创建实际练习团队与项目，填写需求，生成教学模板，修改草案和负责人，确认发布，再从当前阶段任务链接进入执行台，认领并提交明确标记的练习记录。固定模板只开放给当前账号绑定的教学项目，普通项目仍使用原模型生成链路。验收与集成保留实际权限，本教程认识流程，不自动通过审核或创建虚假导师。后续功能课程仍通过侧栏目录选择项目和角色复习。

账号教程进度保存新建团队、项目绑定，并在鉴权后恢复第一轮本人负责的任务。创建绑定只能由原有鉴权创建动作写入；服务端根据实际数据库草案、已发布任务、认领和提交状态拒绝跳步。刷新不会依赖已丢失的表单临时状态，暂停可续练。重启主线保留原练习项目与其他功能课程记录，新建另一份练习。旧独立练习进度迁移到第零步并暂停，保留旧 JSON 数据。

执行步骤改为高亮原规划页当前阶段任务链接，避免执行台默认排序选中第二轮任务。另修正原执行台 `panel=list` 时自动选中任务并移除列表参数的行为，功能课程在手机和桌面均可显式选择任务。原草案表单采用已有 `ac-field` 样式。
