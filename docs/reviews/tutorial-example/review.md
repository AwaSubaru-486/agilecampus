# 示例项目新手教程验收（2026-10-07）

用户要求按生成示例项目的流程熟悉功能。完整旅程不再串接各功能课程，而围绕“校园活动报名页”完成十四项操作和一次成果回顾，共十五步。

## 流程与实现

1. 组长：命名团队、创建项目、写目标与完成标准、生成教学模板草案、调整任务与负责人、确认发布。
2. 组员：接任务并写执行计划、向教学 AI 提问、报告阻塞、登记共享资源、提交交付证据。
3. 导师：检查组员证据、写验收意见并通过任务验收。
4. 组长提交阶段集成，导师审核集成；通过后组长规划下一轮新增需求。
5. 回顾目标、分工、讨论、求助、资源、交付、验收、集成与改进记录。

独立练习区 `/tutorials/example` 将示例状态保存于当前账号的教程进度 JSON。教学模板、预设 AI 回复、组长样例反馈与演练角色均明确标识。正式项目、团队成员、账号角色、真实模型调用及消息发送没有新增写入；无需数据库迁移或模型配置。示例不是生产项目列表中的真实业务项目。

操作保存成功后，目标区域标记完成，教程才允许下一步；服务端同时校验阶段顺序及完成门槛。账号行锁避免重复提交或教程位置保存覆盖示例成果，重复步骤幂等，字段经过长度和白名单校验。暂停与刷新保留位置及已保存结果；重新创建按钮明确提示会重建示例。已完成示例可从目录查看成果。

旧版完整旅程的活动位置迁移为新版第零步并暂停，避免第十一步沿用旧目标。旧版完整路线完成标记不代表已完成新版示例；其他独立功能课程记录保留。侧栏仍有教程入口，目录保留功能搜索、分类、项目和真实角色过滤。
