# 项目版本迭代

用户选择版本管理方案：项目下独立页面，按计划中、进行中和已发布展示版本演进。

## 实现

- 新路由 `/projects/[projectId]/iterations` 和项目导航「迭代」，保留现有时间线。
- 创建、编辑版本号、名称、目标、起止日期、版本说明、关联任务；支持状态筛选、空态和真实任务验收进度。
- 组长管理，组员和老师查看；切换到成员操作视角时同样受该成员权限约束。
- 校验项目内版本号唯一、有效日期和任务归属，不允许把任务分组作为工作量计入。
- 开始迭代后，关联任务全部处于 `done` 才允许标记已发布。未关联任务的迭代可以发布文字说明。发布只登记项目交付，不执行代码部署。
- 发布保存任务名称、负责人和状态快照；后续重开、修改、删除任务不改写历史。发布版本不可编辑，后续调整新建迭代。
- 写入和活动记录在同一事务内；项目锁与版本更新时间校验避免并发覆盖。关联迭代不修改任务状态。
