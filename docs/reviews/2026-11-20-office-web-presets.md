# 空工位入口与三种网页桌宠直接入座

用户指出点击工位无响应。原因是旧点击目标只覆盖已入座桌宠头部，空工位与桌面没有点击行为，未绑定桌宠时也不能直接开工。

改为整张工位及名字框可点击，打开当前账号面板。面板直接显示网页版现有的小狗、吃豆人、奶龙三种预览与选择。保存选择使用原网页配置接口，同时关联办公室。点击开始工作时自动保存当前三选一形象再开工，不再要求用户先从浮动桌宠设置保存一次，也不要求先绑定旧演示宠物。换形象会同步浮动网页桌宠，后端权限与项目隔离保持原样。独立 exe 的桌面陪伴折叠为可选项，不参与网页入座流程。

本轮办公室主流程仅提供三种预设，后台已有自定义上传能力及旧演示记录未删除。工位展示仍为网页桌宠形象在办公室中的坐姿展示，浮动窗口的位置不搬入工位。

验证：生产构建通过，全站 lint 0 错误、30 条已有警告，最终页面文件 ESLint 通过。真实浏览器以没有任何桌宠绑定的新账号点击自己的空工位，逐一选择三种形象、开始工作并读取实际工位资源，确认字节与对应预设图片完全相同，同时验证结束工作离座和手机端点击。脚本 `.local/verify-three-presets.cjs`，本地 3000 服务已更新。
