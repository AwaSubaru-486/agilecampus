# 看板求助任务进入协作中心

项目看板的协作中心按需要帮助的任务展示，主标题改为任务名称，下方显示发起人和具体需求。同一任务多条求助合成一项，整项可点击。无关联任务的项目求助通过“查看项目全部求助”保留入口。

点击后进入 `/collaboration?project=…&task=…#task-…`，筛选对应项目并自动展开和定位目标任务，显示任务目标、完成条件、全部相关求助及原有“标记为已解决”表单。协作中心也展示本人发起的求助，修复之前从本人看板跳过去看不到的问题。已结束或不可见的求助显示通用提示，权限仍按团队成员检查。

处理动作复用原求助领域方法；解决后刷新协作中心及求助实际所属项目。解决求助只解除阻塞，不自动完成或验收任务。

验证：28 项相关测试通过，覆盖按任务分组、深链接、本人求助、项目筛选、跨团队权限和解决后的列表变化；生产构建和文案检查通过；ESLint 0 错误、30 个已有警告。

在 Edge 实际点击汪汪队“敏捷开发平台”看板中的“技术选型与架构决策记录”，确认到达协作中心对应任务，自动展开任务要求、求助与处理按钮。没有提交该真实求助的解决表单。截图为 `task-help.png`。
