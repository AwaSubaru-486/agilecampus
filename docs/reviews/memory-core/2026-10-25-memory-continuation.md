# 任务记忆继承：实现、接线及验证

日期：2026-10-25。范围：用户个人会话记忆模块，以及既有 Agent 启动器的最小接线。

更新：2026-10-26 已实现网页入口、版本存储、任务对话上下文与 VS Code 深链接。下文“只有命令面板”“界面由前端负责人完成”是当日历史状态；最新结果及仍未实测的边界以 [网页任务记忆记录](2026-10-26-web-memory-design.md) 为准。

## 本轮行为

原来的已确认记忆可生成、导出、导入和复制，但与检查点启动命令没有直接绑定。本轮新增 `agilecampus.continueTaskMemory`，复用原启动器，提供以下过程：

```text
接受或导入固定记忆版本
  → 当前账号/工作区/项目/任务的本机记忆库
  → 选择匹配检查点和写入工作区
  → 选定精确记忆版本，查看代码及来源核对
  → 用户确认启动
  → 新 Agent 实际接收这份记忆
  → 尝试记录保存继承来源，新会话独立记录
  → 后续提炼引用父记忆
```

已接受版本在生成接班材料时同时登记到任务记忆库；历史已接受版本可通过重新打开审核命令并生成材料登记。导入材料也进入同一个库。库按现有 actor scope、workspace scope、项目和任务隔离，读取重新校验格式、摘要和归属。损坏、篡改或不安全文件明确失败。

核对报告包含记忆 ID/revision、来源会话与事件截止范围、旧代码 SHA、当前代码 SHA、采集缺口和预算遗漏。代码或范围不匹配阻止启动，不能换成另一个版本假装继续成功。历史测试和推测仍保留各自证据类型；Agent 启动时须先读当前代码并说明下一步。

实际启动 prompt 中注入已选版本，包含目标、约束、进度、决策、失败方法、阻塞、下一步、历史测试与来源引用。不会把记忆作为附件重复发送。上下文超过 192 KiB 时拒绝，避免静默截断。旧检查点启动命令保留显式不使用记忆的路径；新增命令必须有已确认记忆。

`LocalAttempt.memoryInheritance` 保存固定的 memoryId/revision、materialId、两个摘要、来源 sessionKey、来源事件区间和代码基线。记录绑定后不可改为其他来源，也不能把尝试基线改成与记忆不同的 SHA。旧尝试没有此字段时仍可读取。

只有收到 CLI 的真实 session 回执才绑定新本机会话；注入的记忆作为实际传入的 user 上下文事件记录，CLI 最终回复作为 assistant 事件记录。若本机记录失败，停止 Agent 或将结果保留为待核对，不能显示可靠交接。父会话与其他方案不共享可写事件日志。再次提炼通过已记录的原生会话关联查找父记忆；本地路径比较使用 realpath，兼容 macOS `/var` 与 `/private/var` 别名。

## 给前端/worktree 组员的入口契约

当前只有命令面板入口，未改网页、Webview 布局或任务状态。扩展内可以调用：

```ts
await vscode.commands.executeCommand("agilecampus.continueTaskMemory", {
  taskId,       // 必需：若传参数，必须指定当前任务
  checkpointId, // 可选：固定检查点
  materialId,   // 可选：固定记忆材料版本；找不到就失败，不自动换版
});
```

不传参数时提供项目内选择。传参时只查指定任务及指定版本；参数拒绝未知字段和非法 ID，调用方不能传工作目录或运行命令。仍按绑定项目在线核对任务权限，仍由用户选择写入位置并确认。导入完成后的“从任务记忆继续”会带入 taskId 和 materialId。

任务视图的主要操作可以命名“继续工作”，展示固定记忆及其接续结果。网页需通过既有扩展桥接机制交给本机执行；普通网页按钮不能直接调用上述 VS Code API。网页只显示已获取到的材料/回执，不把按钮点击当成已启动。此界面集成由前端负责人完成。

worktree 负责人继续提供隔离工作区、对应检查点和确切 SHA；本轮不新增分支创建、代码快照恢复、自动合并或任务验收。准备好的旧 worktree 尝试可通过既有启动器选择，并携带此记忆启动。
