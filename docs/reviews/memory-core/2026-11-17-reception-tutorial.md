# 接续防重与新手导览

- 集成分支已包含 GitHub PR #7 的提交历史；PR #6 合入时保留已有的独立 `npm run dev:webpack`、生产启动脚本、TypeScript 排除项及认证配置。未更新 PR 指向的旧 `master`。
- 接续请求按账号、项目、任务串行创建和领取。已领取的接续不因回执静默而失效；未领取达到 10 分钟可以重试。旧请求 ID 的重试沿用原记录，其他队友可独立发起。无需数据库迁移或升级 VS Code 0.1.9。

- 当前验证范围是任务记忆与教程自动化测试、生产构建；未进行登录态浏览器及跨机器实际演练。
