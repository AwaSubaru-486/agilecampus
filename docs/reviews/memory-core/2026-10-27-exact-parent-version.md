# 精确父记忆版本

## 本轮结果

新记忆可记录 `parentReference: { memoryId, revision, memoryDigest }`。精确引用来自已确认的本地父记忆，或真实接续尝试中保存的继承回执；模型不负责生成这些字段。

链路：接续回执 → 新会话提炼 → 草稿落盘 → 人工确认 → 导出材料 → 服务端保存 → 网页查看。

网页继承来源显示父记忆的修订号。列表中父版本 ID、修订及内容校验值同时匹配，才提供“查看继承的版本（内容校验匹配）”。比较区提供“与继承的版本比较”，不取最新版本代替。

服务端已有父版本时，拒绝内容校验不一致的引用；同一会话存在不同修订或不同内容的继承回执时，插件拒绝猜选其中一份。

## 兼容与范围

- 原有记录没有 parentReference 时仍可读取，明确显示没有精确修订号；不补造历史信息。
- 父版本未发布或不在最近 50 份列表中时，保存引用但不声称校验匹配，网页提示无法确认来源内容。
- 校验值只能确认引用内容是否相同，不能证明发送者真实身份或模型已经理解。
- 数据在现有 JSON 字段中，无新增数据库迁移。
- 新格式需要本轮网页服务和插件 0.1.3。旧插件的严格解析器不支持新增字段，应升级后接收新记忆；旧材料仍可导入。
- 不修改任务状态、worktree 或最终验收。真实双机接班仍需验证。

## 验证重点

父版本后续变化不能改变已有引用；多份同 ID 不同修订回执必须报冲突；不同任务不串联；旧记忆可读；新的草稿、确认文档和导出保留精确引用；服务端拒绝与已发布父版本不一致的校验值。

实际结果：插件相关 17 项测试通过；网页记忆与共享会话契约、访问、提炼的首轮 40 项通过，新增父版本服务端校验用例后，记忆专项重跑 20 项通过。网页生产构建、插件编译及定向 ESLint 通过。安装包为 `vscode-extension/agilecampus-memory-lineage-0.1.3.vsix`，未安装或推送。

浏览器在独立测试库验证：精确父版本匹配后提供查看入口，点击“与继承的版本比较”正确选中父记录并显示新增进展及下一步变化。截图：`web-evidence/exact-parent-version.jpg`。使用合成会话，没有启动真实 Agent。
