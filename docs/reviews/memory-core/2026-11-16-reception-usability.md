# 任务接班体验 0.1.9

## 网页

沿用项目的白色面板、深色正文、状态色和系统中文字体。任务接班区按“断点身份 → 接下来做 → 接续 → 查历史证据”排列，窄屏改为上下堆叠，主操作加大触控面积；没有新增全站颜色、卡片或动画。

- 首次选中断点后，刷新或队友上传不会替换正在查看的版本；需要切换时点“查看最新断点”。指定旧版本仍精确读取，不兜底。
- 列表出现新版本只能说明有人上传，不能确认是当前插件窗口。同步对话框给出核对提示，不自动关掉，也不替用户切换版本。
- 停止自动轮询后，本地计时仍会更新。未领取请求达到有效期后可重试；发起前先重新向服务端确认旧请求没有被领取。已领取但迟迟没有新回执，只提示检查原工作区，不改执行结果、不解锁重复启动。

## 插件

在匹配仓库中比较两个已提交的文件树。预览优先列出明确提到已变动路径的完成项、决策、失败方案、阻塞、下一步及历史测试命令。只匹配字面相同的路径；不能推断依赖关系、判断旧结论失效或说历史测试已重跑。未匹配和路径截断都不能视为安全。基线不符仍走原阻止规则，没有自动切分支、改代码或启动 Agent。

## 验证与边界

- 网页记忆相关 26 项测试、插件迭代专题 6 项测试通过；插件编译和 VSIX 完整性通过。
- 浏览器能打开本地服务登录页；本机演示账号未能登录，未对登录后任务面板做浏览器验收。
- 未加团队指定默认断点、自动解除领取、自动合并或新数据库迁移。
