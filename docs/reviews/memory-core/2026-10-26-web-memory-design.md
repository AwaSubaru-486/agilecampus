# 网页任务记忆工作面

用户授权把记忆继承接入网页主路径。本轮允许修改任务详情、记忆专用接口、数据库及 VS Code 深链接接线，不接管任务状态机或 worktree 操作。沿用 anti-ai-slop-ui 与 ui-ux-pro-max 的层级、反馈及可访问性约束。

设计方向：Developer Tool / Command Center。高校代码团队打开任务后，应在五秒内知道上次做到哪里、下一步是什么、如何继续。沿用项目已有 sans 字体用于中文内容、mono 仅显示 SHA，14px 正文、12px 元数据、16px 分区标题；复用 panel/ink/stroke/signal 语义色，不改变全站主题。间距 8/12/16/24px；模块无额外卡片、彩色竖线、虚线框、阴影或装饰动画；按钮使用既有 ac-btn。任务列表在左，当前任务工作记忆在右侧详情的最上方。次要历史和技术细节按需展开。

主要动作：保存断点、继续工作。保存打开原生 dialog：从已连接的 VS Code 同步已确认记忆，或导入接班 JSON；文件先预览再明确保存给项目成员。继续工作可复制可核对的上下文，也可在 VS Code 获取确切版本并启动既有接续流程。打开 VS Code 不代表已启动或代码核对通过。网页不模拟读取本机磁盘。

常驻展示：记录人、时间、版本、代码 SHA；已完成、阻塞、下一步。完整记忆和来源覆盖可展开；历史按列表展示。同一来源不可变，导入其他任务的材料明确失败。无数据时给出具体保存动作；加载失败显示重试，不能伪装成“暂无记忆”。

视觉验收：键盘可打开/关闭弹窗、焦点返回；文件有标签，错误 role=alert；读写动作各有 pending；切换任务不会串记忆；窄屏按钮换行，文本不截掉关键下一步；不增加无意义的统计卡片。

## 已实施的用户路径

1. 分工与执行 → 点击任务 → 标题下面直接看到“当前工作记忆”，不需要展开交接技术详情。
2. 保存断点 → 从已连接的 VS Code 选择已确认记忆并确认发布；或选择记忆 JSON，先预览再勾选共享确认。未生成记忆时插件提供当前任务的提炼/审核路径。
3. 已保存后显示版本、作者、时间、代码基线、进度、阻塞和下一步；历史版本及完整来源按需展开。保存的是不可变版本，不覆写旧记忆。
4. 在 VS Code 继续工作 → 获取所选固定版本 → 校验任务与本机代码 → 进入既有预览和人工启动确认。URI 打开本身不是完成回执。
5. 开始任务对话 → 同一任务的对话工作面 → 载入记忆继续对话 → 编辑并发送请求。模型实际接收历史上下文，成功后会话和消息记录确切版本；后续消息及分叉保留继承关系。任务链接不会回落到其他任务的最近对话。

服务端校验成员权限、任务归属、来源地址、包摘要及版本一致性；无效 Bearer 不退回 Cookie。只共享已确认摘要，不上传原始对话或代码。迁移位于 `scripts/migrations/2026-10-26-task-memory-versions.sql`，已在本机开发库和独立测试库应用，无数据重置。其他部署需自行应用。

- 扩展完整测试：32 文件、182 项通过；包括 URI 注册处理、明确发布确认、取消不发请求、固定版本落盘、代码基线检查及错误服务器/dirty 工作区阻止启动。
- 新增网页专项 7 项：真实 PostgreSQL 和临时 Git 仓库、权限/摘要/任务隔离、实际编排模型请求含所选失败方案记忆、逐消息引用、后续轮次/分叉继承、模型失败不写入成功绑定。模型使用 AI SDK 测试替身，不消耗真实 API。
- 根目录生产构建、扩展类型检查及打包通过；本轮修改文件定向 ESLint 无错误/警告。全站 lint 无错误，37 项既有警告未在此范围清理。

技能对实现的约束：anti-ai-slop-ui 促使本轮只增加任务主动作与行式内容，不增加统计卡片、装饰竖线或营销标题；ui-ux-pro-max 用于文件错误、原生弹窗、键盘与窄屏状态。按技能量表的主观复核：模板化程度约 2/10、任务针对性约 8/10；不是用户研究或客观实验分数。

## 交付与边界

新版扩展包：`vscode-extension/agilecampus-memory-web-2026-10-26.vsix`。已生成，未自动安装、未发布市场、未推送 GitHub。旧插件没有本轮 URI 入口，须安装新版或运行源码 Extension Host，并绑定同一个服务/项目和 PAT。

本轮没有真实双人跨机器 Extension Host + 模型端到端证明，不能宣称完整异机接班验收。网页 AI 仍是项目工作助手，不具备直接执行本机代码的能力；代码继续执行走本机插件。网页聊天本身尚未增加自动提炼上传按钮。新版本展示的是历史记忆与历史测试，不能冒充当前代码已验证。工作记忆不是 Git 备份，也不恢复原生模型隐藏上下文，不改队友 worktree、任务验收或账号逻辑。
