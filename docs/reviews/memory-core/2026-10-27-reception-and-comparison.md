# 接班核对与记忆比较

## 使用入口

项目 → 分工与执行 → 选择任务 → 当前工作记忆。

展开“接班核对要求”，可查看接续 Agent 收到的四项要求：继承进度、待验证结论、失败方法、第一项行动。网页对话和 VS Code 接续共用同一份要求，实际回答仍在对应会话中查看。页面不会自动宣称 Agent 已理解，也没有将提示词变成强制执行的状态门禁。

任务至少保存两份记忆时，展开“比较记忆变化”，明确选择对比基准。页面按目标、完成项、阻塞、失败方法、决策、约束、待完成及下一步展示新增和移出的文字；代码基线不同时另行显示。它是文字比较，不做语义推断；移出阻塞不能算作已解决。

## 给组员展示

1. 打开已有真实断点，展示失败方法与下一步。
2. 进入插件接续，检查 Agent 首次回复是否包含四项核对结果。
3. 接续工作后保存第二份记忆。
4. 网页选中新断点，展开比较，选前一次断点，解释新增进展和下一步变化。

版本修订号只在同一记忆 ID 内有意义。两个独立记忆都可能显示 r1，不能靠修订号判断先后或继承关系。选择器同时给出作者、时间和记录 ID，父记忆的精确修订仍待补充。
