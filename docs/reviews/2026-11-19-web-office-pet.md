# 网页桌宠与项目办公室打通

网页桌宠的账号配置成为办公室的一种真实 HomePetProvider 来源。稳定 ID 为 `web:<ownerId>`，形象、昵称及资源版本从当前账号配置读取。保留旧演示宠物的可读性和选择，不强制重写所有人的旧绑定；网页保存换装或改名时自动关联网页桌宠，办公室也可直接选择这只桌宠。

## 使用

在项目办公室打开“我的桌宠”，点击“装扮网页桌宠 · 同步到办公室”，进入队友原来的设置中心。选择预设、改名或上传图片并成功保存后，办公室马上刷新；其他成员的办公室仍按原 15 秒间隔刷新。配置更新只改变桌宠关联及资源，不重置当前项目工作状态。选择桌宠后按原规则手动开工、收工。

浮动网页桌宠仍由原组件播放多动作；工位使用当前形象配合原有坐姿遮挡和打字动作，不把两个场景的位置或动画时间强行同步。浮动桌宠的显隐与工位开工独立。

## 配置和资源

- 抽出不依赖鉴权的账号运行目录函数；status/sync/办公室共用配置读取，避免默认值分叉。配置写入使用临时文件与重命名；保留原文件格式和目录，未新增数据库迁移。
- 保存网页配置后，服务端关联当前账号的网页桌宠。客户端仅在保存成功后通知办公室刷新；失败显示错误。上传支持 PNG/JPEG/GIF/WebP，最大 2 MiB，修复原 32KB 请求限制导致一般图片无法上传的问题。
- 图片通过 `/api/pets/web/:ownerId/:assetKey` 提供，配置形象变化使资源版本变化。本人可以读取；队友必须能访问宠物主人正在工作的项目，而且主人仍是项目成员并实际选择了网页桌宠。收工后撤销这类队友读取。响应 private/no-store，不公开缓存私人图片。
- 本地文件只允许 public 内的图片，检查真实路径；不读取磁盘绝对路径或目录外文件。data URL 仅允许上述四类图片。外部 HTTP(S) 图片链接由浏览器重定向加载，服务端不请求任意外网地址；外站图片的合影仍受对方 CORS 限制。
- 独立桌面客户端可通过原资源读取接口读取预设、public 和上传图片。外站链接未增加服务器代理，独立客户端仍不能把此类链接当作本地图片读取。
