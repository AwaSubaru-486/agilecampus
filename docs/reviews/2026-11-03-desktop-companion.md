# 独立桌面陪伴第一版

用户要求实现：网页最小化后桌宠仍悬浮在桌面。采用独立 Windows Electron 客户端，保留网页作为项目管理、家园和桌宠选择入口；没有将整个平台打包为桌面应用。

## 交付

- 独立目录 desktop-pet，独立依赖和锁文件，Electron 45.2.1。
- Windows x64 便携程序与 ZIP，位于 `.local/desktop-release`；网页登录后可下载。
- 家园侧栏“桌面陪伴”：生成邀请、唤起、查看实际运行状态、找到桌宠、隐藏、断开。
- 客户端：透明无边框、置顶、拖动、alpha 透明区域穿透、大小菜单、系统托盘、隐藏找回、返回家园/庭院和退出。多屏找回不自动改变家园位置。
- 复用自定义桌宠图片或精灵图的 idle/greet。未接入/未绑定/图片失效明确显示空态，不以测试素材冒充本人桌宠。

操作说明与安装/卸载见 [桌面程序 README](../../desktop-pet/README.md)。首次运行 exe 注册用户级 agilecampus-pet 协议；网页生成邀请后显式点击打开程序，客户端确认平台地址再领取邀请。

## 服务端边界

新增 desktop_pet_connections 一表，哈希保存 90 秒一次性邀请和 7 天受限凭据。并发领取只能成功一次，新连接撤销旧连接。独立凭据仅用于本人桌宠状态、资源和运行回执，不使用项目 PAT，也不会改变任务权限或家园活动位置。

客户端只运行本地 HTML；contextIsolation 与 sandbox 开启、Node integration 关闭，IPC 不接受任意 URL/文件/命令。图片由已验证账号的专用网关读取，限定格式、大小和路径，不将授权凭据交给渲染器。系统加密优先异步 API，Windows 45 异步不可用时回退到系统同步加密；都不可用则不持久化凭据。

新增接口 `/api/home/desktop`、`/pair`、`/state`、`/asset`、`/download`。只有实际心跳且在 30 秒窗口内才显示运行中；请求发送不等于窗口已显示。

## 验证

- 主项目 6 个专项测试文件、37 项通过：一次性/并发/过期领取、明文不落库、撤销与替换连接、真实心跳判定、操作确认顺序、本人资源、图片格式和原家园权限。
- 独立客户端 Node 测试 6 项通过：协议/服务地址边界、图片/图集尺寸、屏幕找回、加密优先级与不可用时不保存凭据。
- 全库 ESLint：0 错误，30 条既有警告。主站正式构建和 TypeScript 通过。
- 使用真实 Electron 窗口检查透明截图 alpha、always-on-top、渲染隔离、拖动、隐藏及显示命令回执。
- 临时测试账号经真实网页生成邀请，客户端领取并返回真实心跳；网页隐藏/找回有效。通过 CDP 实际最小化 Edge 后桌宠仍可见；关闭浏览器后程序仍保持连接。
- 最终便携 exe 直接重复了以上原生流程，验证包内入口和资源完整。系统加密在本机以实际 API 完成往返验证。测试模式不注册协议、不保存测试凭据；测试账号清理。

## 当前限制

桌宠创建和真实资产仍由队友模块提供，当前默认来源是空实现。受保护资产实现 `HomePetProvider.readAssetOwned` 即可接入；公共 public/pets 位图有安全读取兜底。实际动画渲染用合成位图验证，未声称真实自定义桌宠已交付。

本版为未签名 Windows 便携原型，无安装器、自动更新、开机自启或自动读取其他应用。需要平台后端继续运行才能同步，断网时保留已加载资源。不会监听普通浏览器最小化事件来自动启动；使用家园里的显式开启入口。
