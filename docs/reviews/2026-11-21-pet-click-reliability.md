# 互动点击无反馈排查与修正

用户补充现象为按钮点击后面板不收起。本地当前成员双方处于同项目工作状态，最近记录只有此前挥手，没有新的投掷记录。只读登录态浏览器检查显示按钮应可操作，但复现到页面初始化 React 418 渲染不一致错误；不能把这一错误断言成用户浏览器无响应的唯一原因。

网页浮动桌宠的初始化依赖浏览器窗口尺寸和 localStorage，原服务端首屏与浏览器初次渲染会不同。改为 useSyncExternalStore 区分服务端与客户端，客户端完成 hydration 后再挂载桌宠实际内容。保留原设置和视觉，不改账号权限。

互动按钮增加明确发送中提示、十秒请求超时、响应格式与回执校验、按钮上方错误提示和逐秒冷却说明。条件不满足时保留 aria-disabled 说明，但点击会给出具体阻止原因，不再依靠无反馈的原生 disabled；真正发送仍先检查条件，后端权限与冷却保持不变。请求进行中仍原生禁用，避免连续发送。

验证：生产构建通过，全站 lint 0 错误、30 条已有警告。双账号浏览器预置与服务端不一致的旧缓存，确认无 React 初始化错误；模拟服务返回 503 时显示错误且保持面板打开，恢复请求后能发送纸飞机并检测 SVG 位置变化；验证双向投掷、冷却、收工不可操作和手机面板。脚本 `.local/verify-reliable-interaction.cjs`。另只读查看本地实际成员面板，确认初始化脚本错误为空，没有代替实际成员发送互动。已在默认浏览器重新打开项目，使用最新脚本。
