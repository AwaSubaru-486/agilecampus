# 汪汪队新手教程重构

主线改为展示已有的“汪汪队 / 敏捷开发平台”。从用户有权限的项目列表中选择同名项目，优先使用有任务的一份，本地实际绑定到 42 项任务的项目 `f82b8973-200a-4cb3-9a08-00773eebd8f5`。目录也默认使用此项目，选择器增加团队名与实际任务数以区分同名项目。

组长路线共 24 步：教程目录 → 实际成员 → 恢复组长视角 → 分工 → 看板与我的任务 → 查看实际任务 → 当前阶段进度 → 连续任务树、阶段定位与任务小窗 → 组员和老师预览 → 合并成果复核与集成审核 → 返回组长、项目推进台 → AI 项目对话 → 成果与活动记录 → 功能目录。组员不进入成果与记录或评审页，老师不进入执行、AI 或组长视角切换步骤。

主线只要求查看页面、选择节点及角色预览，取消模型配置、创建团队、生成发布草案、认领及提交练习成果的门槛。旧版本主线升级到 v6 后暂停到新起点，保留其他功能课程进度及旧团队项目。旧校园报名模板不再拦截展示项目的正常模型生成。教程开始、保存与切换步骤接入真实加载动画。

任务小窗关闭按钮增加定位入口；刷新后恢复小窗步骤会返回打开节点的步骤。任务列表高亮只展开定位所需的阶段，其他阶段保持折叠。阶段定位高亮整个阶段导航，允许选择任一阶段。
