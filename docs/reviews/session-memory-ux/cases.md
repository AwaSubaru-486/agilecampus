# H00–H02 验收用例

每个本地测试用例均使用临时目录与合成 hook payload，不读取个人对话，不代表真实 Codex Extension Host 验收。

| ID | 验收场景 | 预期 |
| --- | --- | --- |
| H00-01 | 查看侧栏命令入口 | 标题栏只保留刷新；连接入口仅在未连接时出现；历史命令仍注册 |
| H01-01 | 未选任务 | 不允许把来源绑定到未知任务；显示选择任务入口 |
| H01-02 | 未发现 Entire session | 不写绑定；显示 CLI/版本/无来源的可恢复说明 |
| H01-03 | 用户取消本地原文存储确认 | 不创建绑定/不写 Hook 配置 |
| H01-04 | 绑定冲突 | 不改已有任务绑定；原位说明需选择未绑定会话 |
| H02-01 | 相同 Codex hook 重试 | 同一个 sourceRef 只产生一份记录 |
| H02-02 | session/workspace 不匹配 | Hook no-op，不采集其他 workspace/session |
| H02-03 | Prompt / PostToolUse / Stop | 以用户、工具输入、工具结果、助手结束序写入本地事件 |
| H02-04 | 超过单事件大小上限 | 写明原因的 gap 事件，不静默显示正文完整 |
| H02-05 | 分页首屏 | 最新 50 条，序号连续，工具内容按需可读 |
| H02-06 | 加载更早页 | 读取前一页，不丢焦点、不跳到最新 |
| H02-07 | 序号缺口/坏 JSON | 显示明确读取错误，不以空列表掩盖 |
| H02-08 | 会话停止记录 | 后续 Hook 不追加；本地历史仍能读取 |
| H02-09 | Codex 尚未信任 Hook | 仍显示等待状态，不显示实时记录/接收中 |
| H02-10 | Claude Code | 当前版本明确显示未支持，不显示“已接入” |
| H02-11 | 无 AgileCampus Hook 时使用禁用命令 | 配置不变并明确显示无变化；已有其他 Hook 不受影响 |

真实验收至少需要：VS Code Extension Host、已装配 AgileCampus 扩展、Entire/Codex CLI 的支持版本、专用于验收的非敏感测试任务、用户自己确认 Hook 记录与 `/hooks` 信任。缺一项时记录为 BLOCKED，不以单测替代。
