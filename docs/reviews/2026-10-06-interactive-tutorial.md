# 网站互动新手教程

## 已实现

- 首次进入登录后的应用时询问是否开始；开始、跳过和 Esc 均保存账号记录。
- 页面内聚光高亮真实入口；点击与填写步骤检测实际操作并即时反馈，未完成时禁用下一步。需求说明按至少 10 字校验。
- 自动进入对应页面并滚动定位；打开弹窗或点击阶段锚点后展示操作结果。包含上一步、暂停/退出、缺少前置数据的说明和重新定位。
- 侧栏常驻 `/tutorials`：完整旅程、14 个功能课程、真实项目选择、完成记录与断点继续。
- 完整路线按项目中的实际团队角色过滤：组长学习规划和执行；组员学习执行；导师学习审核和评审。
- 功能课程覆盖团队成员、生成草案、执行交付、验收、阶段迭代、复盘活动流、AI 会话、可见范围、上下文包、证据档案、时间线、风险求助、资源、标签看板、AI 成员、工具连接与账号通知。
- 教程不自动提交业务表单、创建会话或令牌、调用模型、冻结资料或发布任务。执行这些动作仍使用原有页面及服务端权限。
- 窄屏展开需要的导航，正文步骤收起导航；提示卡避开低位按钮。会话的上下文包区域在窄屏也能使用。

## 服务端与部署

`users.tutorial_progress` 保存首次提示状态、已完成课程以及当前课程、步骤、项目和暂停标记。Server Action 从登录会话取得账号，拒绝无权项目、越界步骤和不适用角色。行锁保护并发完成记录的合并。

本地开发库及隔离测试库已应用 schema。部署此版本前需要按项目现有流程运行 `npm run db:push`，或执行 `scripts/migrations/2026-10-06-tutorial-progress.sql`。SQL 只增加列；已有账号会收到一次提示。

同账号跨请求、刷新和重新登录使用服务端记录；跨设备续接依赖相同后端账号，未做异机实测。教程覆盖网页操作；VS Code 插件的安装、真实会话采集和外部 Agent 恢复仍需要在对应工具中完成。
