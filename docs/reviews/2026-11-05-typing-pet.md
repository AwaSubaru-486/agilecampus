# 工位轻微打字动画

在已有工位 SVG 中对工作桌宠增加低幅度前倾、起伏，配合键盘按键错峰下压和变色、屏幕光标闪烁。键盘移到桌宠面前。仅工作中且资源可用的桌宠播放；打招呼暂停身体和按键动画，结束工作移除桌宠及动画。沿用原图片和精灵图，不将静态图片描述为真实手臂逐帧动画。

动画使用 CSS，继承现有 reduced-motion 全页禁用规则，不增加定时轮询或修改工作状态。合影仍为静态 SVG。

验证：生产构建通过，全站 lint 0 错误、30 条已有警告；真实浏览器采样确认身体变换随时间改变，键盘反馈存在，模拟 reduced-motion 后 animationName 为 none，同时验证开工、收工、刷新、窄屏和合影。脚本 `.local/verify-typing-pet.cjs`。本地 3000 页面已更新。
