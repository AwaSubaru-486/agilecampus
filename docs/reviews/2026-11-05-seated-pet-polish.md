# 工位桌宠展示修正

旧实现把站姿图片裁切后单独放在 HTML 椅背前，图片、椅子、桌子分别定位，容易出现站在桌面上的视觉错觉。

改为在 WorkstationArt 同一个 SVG 坐标内依次绘制椅子、桌宠、桌面和屏幕。桌宠与椅背中心对齐，桌面自然遮挡下半身，并增加桌面接触暗部。HomePetAvatar 的可选 seated 展示去除脚底阴影，普通展示不变；图片和精灵图仍使用原来源定义，不增加对具体桌宠 ID 的判断。该方式调整展示和遮挡，没有生成新的坐姿动画。

点击打招呼保留可聚焦按钮，提示气泡位于桌子前；合影以完整工位 SVG 导出，使网页和导出文件具有相同的层级关系。

验证：生产构建通过、实际运行构建指纹 ready，相关文件 ESLint 与全站 lint 检查通过（全站原有 30 条警告）。真实浏览器验证开工显示、收工移除、刷新保留、窄屏以及 SVG 合影包含桌宠图片且几何坐标有效；查看实际截图确认遮挡效果。本机脚本 `.local/verify-seated-pet.cjs`，截图 `.local/workstations-working.png`。本地 3000 服务已更新。
