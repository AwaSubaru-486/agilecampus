# 办公室工位与手动工作状态

用户确认使用手动“开始工作 / 结束工作”。保留现有办公室背景，增加六个可见工位，按团队人类成员的创建顺序和 ID 固定分配；超过六人时分页。成员未工作时只显示空椅，工作且桌宠可用时显示桌宠坐在桌后。团队成员的其他家园布局和任务状态不受影响。

`home_profiles.working_team_id` 是独立状态：开始时验证登录账号、团队成员身份及桌宠归属与可用性；结束允许无桌宠或已经离队的账号操作。一个人同时只在一个团队工作。选择或清除桌宠会结束原工作状态，旧的 `pet_team_id` 庭院位置不会自动转成工作中。进入办公室的队友能看到开工者的桌宠，此行为由开工动作声明。没有启动自动开工或任务状态联动。

网页每 15 秒同步。关闭网页不会自动收工，也不表示实时在线，页面已明确提示；用户休息时手动结束。桌宠模块继续提供原 HomePetProvider 定义，未假造新的自定义桌宠。已有静态演示图通过遮挡展示坐姿；并未为图片生成新的坐姿动作。

部署先执行 `scripts/migrations/2026-11-05-home-workstations.sql`（幂等新增列及团队外键），再启动新版网页。本机开发、测试库均已应用。
