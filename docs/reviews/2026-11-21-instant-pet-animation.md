# 点击即播放，后台同步

用户明确不需要等待队友回应。互动点击通过现有本地开工、目标和冷却检查后，立即创建本页播放事件、关闭面板并播放动画；不再等待 POST 回执。原网络请求只负责后台保存并同步给同项目页面。

成功回执及轮询记录会去重，不重播本页刚播放的动画。请求失败或超时不取消本页动画，在页面上明确提示“本页动画已播放，但暂未同步给队友”，不伪造远端送达。原权限与服务器冷却保持不变。

验证：生产构建通过。全站 lint 首次检查发现一处时间调用的纯度告警，改用已生成事件时间进行计算后，涉及文件 ESLint 通过，其余全站原有 30 条警告不变。真实双账号浏览器故意延迟服务器回执 2.5 秒，确认回执之前面板已关闭且投掷层已出现；后台同步后对方可见，本页 DOM 不因回执/轮询重建重播。模拟 503 时仍能本页播放并显示准确同步失败提示。脚本 `.local/verify-instant-animation.cjs`。本地服务已更新。
