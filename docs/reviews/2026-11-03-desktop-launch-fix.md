# 桌面陪伴唤起与打开网页修正

本轮只修改家园桌面陪伴入口及独立桌宠程序，不涉及任务和记忆模块。

- 网页主按钮取得邀请后直接尝试唤起客户端，保留明确的手动重试链接；未过期邀请可以复用。浏览器外部应用确认和客户端服务地址确认仍需用户操作。状态继续以客户端真实心跳为准。
- 桌宠打开家园或庭院后重新显示并设置置顶，不抢走浏览器键盘焦点；浏览器打开失败显示错误并恢复窗口。失去焦点时也维护已有可见窗口的置顶状态，手动隐藏不会被此处理撤销。
- 新窗口使用 180 × 220 小尺寸；Windows 可能对实际窗口尺寸取整。菜单调整大小时保存配置，原有已保存尺寸继续恢复。

排查时当前演示桌宠进程仍然存在，源码没有打开网页即隐藏或退出的逻辑。因此没有将“被浏览器遮挡”标成已复现的唯一根因；这次增加的是窗口显示保障。

验证：网页唤起工具两项 Vitest、客户端六项 Node 测试和涉及文件 ESLint 通过。真实 Electron 窗口测试通过工具栏打开系统默认浏览器，检查两秒后桌宠仍显示、置顶且保留演示；模拟打开失败时恢复窗口并显示错误；手动隐藏仍有效。测试脚本保存在本机 `.local/verify-pet-open-home.cjs`。

全站生产构建通过；全站 lint 为 0 错误、30 条已有未使用变量警告。重新生成 Windows 便携目录和下载 ZIP，并验证打包版本的透明小青图片、演示标签及键盘打招呼。最后重新打开本机演示客户端。
