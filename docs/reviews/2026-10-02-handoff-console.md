## 本轮设计

开发者工程控制台，保持用户要求的黑灰 shadcn 风格。背景使用已有 ground/panel，边线 stroke，正文 ink，辅助信息 ink-2；system sans 用于中文操作，mono 仅用于 ID/日志。正文 14/20、元信息 12/18、标题 16/24；间距 4/8/12/16/24；分栏无圆角和阴影，控件 6px；仅必要状态反馈，无装饰圆点、彩色竖线、虚线框、营销副标题。

默认执行页：任务行列表 + 所选任务的交接契约/资料/成果 + 真实执行轨。任务是贯穿所有区域的选择对象。窄屏列表与详情互斥，提供返回任务按钮；执行记录仍可见。已完成任务默认收起。旧看板保留在显式“看板”入口，旧 live 链接转到执行页。会话作为任务详情的操作区域，不再独占默认首页。未绑定任务的历史会话保留在“项目会话”入口。

复用既有只读投影、权限、任务动作、上下文冻结和会话 fork API。新增网页交接表单只包装既有 updateTask，保持任务状态机。选定会话、运行、审批必须属于同一任务；无数据不制造运行/检查点。会话分支不等于 worktree 或原生 session 恢复。

## 能力边界

网页可以展示任务关联的运行、交接契约、冻结资料、会话和证据。VS Code 检查点当前存本机，手动 JSON 传递；没有共享同步 API。网页不得声称能够远程恢复本机 Agent。下一步是检查点上传与授权读取契约、代码版本核对，以及将本地尝试映射到任务执行记录。
