# 家园页面只保留团队庭院

按用户要求移除“我的家园”“成员家园”栏目，以及个人布置、成员串门入口。`/home` 统一读取团队庭院；旧 `view=mine`、`view=members&owner=...` 链接也进入庭院，仅保留团队选择参数。错误页返回链接同步改为团队庭院。

保留团队切换、桌宠选择、进出庭院、打招呼、合影、桌面陪伴。原“带伙伴回家”改为“离开庭院”。此次仅改网页入口与展示，不删除已保存数据或改动桌宠来源接口及后端权限。

验证：生产构建通过，全站 lint 0 错误、30 条已有警告。使用临时账号通过真实浏览器验证无团队空态、默认庭院和旧链接、栏目移除、选择桌宠与进入/离开庭院，以及 390px 窄屏无横向溢出；测试后清理临时用户和团队。脚本和桌面截图位于本机 `.local/verify-courtyard-only.cjs`、`.local/courtyard-only.png`。本地 3000 端口已启动更新后的生产服务。
