# 工位互动标识及时清理（2026-11-22）

用户要求工位右上角互动标识及时消失。原来互动状态保留 9 秒，图标摇动结束后仍会留在工位上。本批将互动状态缩短至 2.2 秒；到时清除图标、互动气泡及场景顶部的动画播放提示，并恢复桌宠正常工作状态。

连续互动时，图标按新事件重新播放动画并重新计时。旧事件的清理回调核对事件 ID，避免清除较新的互动。独立投掷物的并行播放与后台同步保持原有行为。

验证：本地生产构建与 TypeScript 检查、修改文件 ESLint；浏览器使用临时双账号验证连点时新事件不会被旧计时器提前清除，互动停止后标识及时消失、轮询不重新显示已播放事件，以及纸飞机与工位反应均正常清理。临时数据在测试后清理。
