# 按具体成员切换项目视角

2026-10-12：项目右上角的视角选择列出当前小组的具体组员与老师，按角色分组，并保留组长本人入口。当前汪汪队可选择鱼乐、哈哈哈、聂翔和郭诗辉。

选择组员后，看板、我的任务（列表与看板）按所选成员筛选；时间线的本人待处理数量同样使用所选成员。换人后清除上一人的选中任务、运行记录和负责人筛选，保留当前页面。老师视角显示具体老师姓名，并保留已完成成果复核与阶段集成审核。

预览身份仅用于任务展示，读取权限仍由实际登录用户校验，不改账号与团队角色，也不以所选成员身份读取私密对话。预览保持原有提交和管理操作限制。仅组长能选择当前小组的真实成员；外组、AI、角色不匹配或被移除的人选无效。旧的纯角色偏好回退到组长本人。教程同步改为选择具体人员，原步骤标识和进度不变。
