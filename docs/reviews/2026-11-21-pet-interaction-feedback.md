# 互动反馈可见性修正

用户反馈“互动没反应”。只读检查本地当前项目，确认双方已开工且存在真实挥手记录，服务端发送环节成功。旧界面只有约六秒的小气泡和轻微摇摆，图片模式忽略 greet 动作，发送成功后没有明确回执，也没有将视口带回工位，反馈容易错过。

改为成功发送后显示明确回执、关闭互动面板并将办公室滚动到视口中间；仅发送者主动触发滚动，不自动移动接收者页面。场景内增加当次互动提示及放大的对应图标，气泡显示延长至九秒，回应摆动更明显，系统减少动态效果设置仍有效。

图片外观契约新增可选 greetSrc，三种网页预设读取队友已有的第 3 号回应素材，结束后恢复第 0 号素材与打字动作。受保护图片接口只允许固定 -greet 后缀且沿用资源版本与原账号/开工项目授权，不允许任意帧或路径。自定义图片没有额外回应帧，沿用原图。某些预设素材帧本身可能相同，仍由气泡、图标和摆动提供反馈，不声称重新生成了动画。

验证：三个相关测试文件 13 项通过，覆盖回应图片内容及访问权限、互动同步与并发冷却、原桌宠契约。全站 lint 0 错误、30 条已有警告，生产构建通过。双账号真实浏览器验证发送回执、双方请求回应素材、跨账号挥手与咖啡同步、九秒后恢复原图、收工禁用及手机面板；本机脚本 `.local/verify-pet-feedback.cjs`。本地服务已更新。
