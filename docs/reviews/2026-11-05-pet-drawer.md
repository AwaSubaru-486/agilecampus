# 我的桌宠按需展开

将原家园右侧常驻“我的桌宠”面板改为默认关闭的右侧模态抽屉。办公室使用完整内容宽度，页面最大宽度从 1152 增至 1440。点击工位桌宠或顶部“我的桌宠”按钮打开当前账号的面板，保留桌宠绑定、开工收工和桌面陪伴。无桌宠、未工作或无团队时也能从顶部进入配置，无团队时禁止开始工作。

使用原生 dialog.showModal 保证模态焦点范围及关闭后焦点恢复，支持 Esc、关闭按钮和遮罩点击；手机端宽度不超过视口，内容可滚动。工作状态等原有权限和接口不变。
