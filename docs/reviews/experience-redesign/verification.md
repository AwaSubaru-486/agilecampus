# 前端体验重构与验收

## 目标与信息结构

用户要求入口随实际需要出现，降低密度，并形成统一的设计感。

全局工作区采用深青侧栏、浅灰绿阅读面、白色卡片。一级入口为今日、项目、协作中心、教程；团队、资料、账号与连接位于次级区域。桌面侧栏可收起，窄屏使用导航抽屉。

项目共用项目身份与四个工作流程：任务执行、规划与迭代、AI 协作、成果与复盘。进度与风险、时间线、活动记录留在各自流程内；成员、共享资源、标签与 AI 配置通过项目管理菜单进入，并有团队内的上下文导航。

今日将任务认领、验收等动作导向实际上下文。任务页保留列表与详情两栏，先呈现要求和证据；执行记录按需打开抽屉，低频材料与管理收纳，拒绝认领按需展开。阶段页默认当前阶段，历史阶段显式切换，规划表单按需展开。AI 讨论资料准备与项目决策也按需展开。

教程保留完整旅程，增加分类、搜索和角色筛选。定位目标时自动展开祖先 details，项目内导航不再误打开全局导航抽屉。窄屏选择任务后，下一讲解步骤保留该任务；重新选任务的步骤仍强制列表模式。

登录与注册提供明确的协作路径，表单使用可见标签、自动填充语义和基础输入校验。
