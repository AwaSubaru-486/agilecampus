# 工位投掷互动：纸飞机与小纸团

新增 plane（放飞纸飞机）与 paper（丢个小纸团），沿用原项目互动记录、权限、双方开工和十秒冷却。数据库 kind 原为 text，仅扩展类型与 API 白名单，无需新增迁移。队友互动面板自动提供两个新按钮。

办公室用 SVG 在 960 × 600 场景坐标中计算起点、终点与二次曲线路径，投掷物约 1.2 秒到达。纸飞机随轨迹转向，纸团保留纸纹；到达后显示短暂落点光圈。接收者气泡延迟到物件到达后出现。投掷不会修改任务、工作状态或其他人的形象。

若互动的一方工位在别页，画面边缘显示飞入或飞出及文字提示；双方都不在当前页时仅显示互动回执。不同浏览器仍按原四秒轮询同步，非逐帧锁步。系统 reduced-motion 模式隐藏飞行层，保留互动文本和回执。

验证：两个相关测试文件共 10 项通过，覆盖两种投掷、反向回应、无效类型、权限、冷却和数据库清理。生产构建通过，全站 lint 0 错误、30 条已有警告。双账号真实浏览器采样飞行物的 SVG 变换，确认位置随时间改变；验证纸飞机及纸团同步、冷却、收工禁用、回应后恢复、减少动态效果隐藏动画和手机面板。脚本 `.local/verify-pet-projectiles.cjs`，截图 `.local/pet-projectile-flight.png`。本地 3000 服务已更新。
