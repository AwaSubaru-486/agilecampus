# 功能演进与迭代工作台

用户要求上方展示已经实现的模块级功能，同一版本沿同一条竖线排列；下方执行版本迭代，避免与现有任务安排重复。本轮替代 11 月 1 日的任务关联和完成率方案。

## 产品行为

- 功能演进图：仅展示已发布版本，按发布时间从左向右排列；每版沿独立竖线展示新增、完善和修复的功能模块。点击版本查看交付档案，可基于该版规划下一轮。
- 迭代工作台：左侧选择未发布版本，右侧展示版本目标、基准、计划周期和功能变化范围。开始迭代后，记录实施与推进、验证结果、发布说明与成果链接。
- 发布后，模块变化进入上方演进图，版本归档；下一轮单独规划。基于历史版本不会自动复制旧模块为新成果。
- 没有任务选择、负责人分工、任务数量、任务完成率或基于任务验收状态的发布门槛。迭代服务不读取或写入任务表。
- 发布要求明确目标和模块范围，并保存验证结果及版本说明。验证结果是操作者记录的使用验证，不代表自动测试或自动部署。
- 组长管理，成员和老师查看；权限、代理视角和并发覆盖防护沿用现有约束。
