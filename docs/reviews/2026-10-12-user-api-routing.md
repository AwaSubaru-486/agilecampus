# 自动使用用户 API 配置

统一模型选择入口：每次操作读取当前用户加密保存的服务地址、模型名称与密钥。个人配置优先，只有没有个人配置时才使用站点默认服务。个人配置损坏或调用失败时不会悄悄切换到其他服务；密钥读取失败会提示重新保存配置。

原项目对话、任务生成和任务链分析已使用个人配置；本轮补齐健康度综述和会话记忆提炼，将登录用户或访问令牌所属用户传入同一模型选择逻辑。记忆提炼的模型来源字段也记录实际使用的个人模型名称。

服务地址同时支持 API 基础地址和完整 `/chat/completions` 地址，避免重复拼接路径。新保存与已有配置都采用相同规范化逻辑；模型或地址更新后，下一次调用直接生效。留空密钥沿用原密钥的行为保留。前端文件与接口响应结构未调整。

## 验证

- SDK 请求在测试中拦截，确认两个用户各自使用正确 URL、模型名称和 Authorization，配置修改立即生效，未配置用户才使用站点服务。
- 验证完整接口地址、已有配置兼容、加密密钥损坏时拒绝切换默认 API，以及健康度综述与记忆提炼使用个人配置。
- 查询当前用户的非敏感配置状态，确认已有个人配置。未读取或打印真实密钥，未向真实供应商发送测试请求。
- 相关测试 5 个文件、16 项通过；生产构建通过；ESLint 0 错误、30 个已有警告。
